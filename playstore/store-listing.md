## Full description

Ultra.X adalah aplikasi demo bertema premium untuk kebutuhan top up dan pembayaran digital.

Fitur utama:

- beli pulsa
- beli paket data
- top up saldo
- token listrik
- keranjang dan checkout
- riwayat transaksi
- voucher dan promo
- favorit dan repeat order

Project ini dibuat untuk kebutuhan UTS dengan tampilan modern, polished, dan alur aplikasi yang terasa seperti produk digital sungguhan.
