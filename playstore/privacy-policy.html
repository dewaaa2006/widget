Privacy Policy - Ultra.X

Terakhir diperbarui: 9 Mei 2026

Ultra.X adalah aplikasi demo project UTS untuk simulasi top up dan pembayaran digital. Dokumen ini menjelaskan bagaimana data pengguna diperlakukan di dalam aplikasi.

1. Data yang Ditampilkan

Aplikasi ini menampilkan data simulasi seperti nama pengguna, nomor telepon, riwayat transaksi, metode pembayaran, dan voucher untuk kebutuhan demonstrasi antarmuka.

2. Data Pribadi

Dalam versi project UTS ini, aplikasi tidak memproses transaksi keuangan nyata dan tidak menghubungkan pengguna ke sistem pembayaran resmi. Data yang diinput pengguna digunakan untuk pengalaman aplikasi dan demonstrasi fitur.

3. Penyimpanan Data

Beberapa data aplikasi dapat disimpan secara lokal di perangkat untuk mendukung state aplikasi, seperti status onboarding, pilihan pengguna, atau data simulasi lain yang diperlukan untuk demo.

4. Pembagian Data

Project ini tidak dirancang untuk menjual atau membagikan data pengguna ke pihak ketiga untuk tujuan komersial.

5. Keamanan

Kami berupaya menjaga struktur aplikasi dan data demo tetap aman. Namun, karena ini merupakan project akademik, aplikasi ini tidak dimaksudkan sebagai layanan finansial produksi.

6. Hak Pengguna

Pengguna dapat menghentikan penggunaan aplikasi kapan saja dan menghapus aplikasi dari perangkat jika tidak ingin lagi menyimpan data demo lokal.

7. Kontak

Untuk pertanyaan terkait aplikasi ini, kamu dapat menggunakan kontak developer yang dicantumkan pada halaman listing Play Store project ini.
